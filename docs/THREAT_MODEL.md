# Threat model: local portfolio demo

Assets: admin session, device private key và certificate, Device CA key, command signing keys, tenant data, command effects, inventory và audit. Trust boundaries: browser↔server, simulator↔server, backend↔database, provisioned JWKS↔simulator, local filesystem.

| Threat / actor                   | Controls                                                                                                            | Evidence / residual risk                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Admin truy cập tenant khác       | Actor tenant từ auth, tenant-qualified SQL/FK, 404                                                                  | HTTP tests đọc/ghi device, command, assignment, history và audit; DB administrator nằm ngoài trust boundary                  |
| VIEWER/OPERATOR leo quyền        | Server RBAC từng operation                                                                                          | Tests VIEWER không sửa, OPERATOR không enrollment; UI không phải security boundary                                           |
| Cookie CSRF / refresh replay     | Spring WebFlux CSRF, Strict cookie, hash refresh, atomic rotation, reuse family revocation                          | Concurrent refresh test; lỗi mạng không tự retry; stolen live access JWT vẫn có thể dùng cho tới logout/revoke/expiry        |
| Token theft                      | Short access JWT memory, HttpOnly refresh; device dùng proof-of-possession thay bearer token (proof một lần, ±60 s) | Local state 0600; XSS trong origin vẫn nguy hiểm. Không lưu token trong audit. Không triển khai trên Internet bằng demo HTTP |
| Enrollment double spend          | Row lock + atomic transaction                                                                                       | Concurrent enrollment chỉ một thành công; audit insert failure rollback token/device                                         |
| Command tamper / substitution    | ES256, strict typ/alg/kid, issuer/audience/tenant/jti/time, provisioned trust + signed trust bundles                | Java–TypeScript fixtures, tamper/wrong identity/key/expiry tests; server signing key bị chiếm cho phép giả lệnh              |
| Duplicate delivery / mất result  | Server leases, stale-attempt reject, local atomic effect+dedup outcome                                              | E2E crash sau persist trước result, restart không lặp message; không cam kết exactly-once trên thiết bị thật                 |
| Revoke giữa execution            | Khóa device trên mutation, cancel/UNKNOWN; auth check mỗi request                                                   | Không đảo ngược tác động đã xảy ra; request đã authorize có thể đang in-flight                                               |
| Stale policy / spoofed inventory | Revision/version matching, server compliance, freshness window                                                      | Stale reports 409; simulator inventory **không** là attestation, agent bị chiếm có thể nói dối                               |
| Private key exposure             | Files ngoài git, separate P-256 keys (access, command, Device CA), simulator chỉ giữ device key của nó              | Local Docker demo không phải HSM/KMS; sao lưu/quản trị keys thuộc người vận hành                                             |
| SQL injection / arbitrary code   | Bound SQL parameters, fixed sort/filter, DTO schemas, no shell commands                                             | Input/negative tests; tránh nhận remote script; device certificate không cấp OS permissions                                  |
| Audit tampering                  | Append-only qua ứng dụng, transactional audit                                                                       | DB owner sửa được; chưa WORM/signature chain/export độc lập                                                                  |
| Resource exhaustion              | Bounded pages/payloads, fetch timeouts, bounded retry backoff                                                       | Chưa rate limit/quotas/retention; demo có thể tăng DB/ledger theo thời gian; cần bổ sung trước public hosting                |

Không bao gồm: hardware attestation, Android Device Owner/Apple MDM, key provisioning phần cứng, FCM, mTLS/certificate lifecycle, tenant billing, distributed multi-region hoặc compliance certification. Các mục này là roadmap, không phải claim trong portfolio hiện tại.
